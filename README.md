# 📚 Плагин для скачивания книг из ЭБС «Лань», «Юрайт» и «Айбукс»

Привет! 👋
Этот браузерный плагин помогает быстро скачивать учебники и научные книги из электронных библиотечных систем **«Лань»**, **«Юрайт»** и **Айбукс** — прямо в формате **PDF**, одним кликом, без лишних телодвижений.

Идеально подойдёт студентам, аспирантам, преподавателям и всем, кто регулярно работает с учебной литературой.

---

## ✨ Возможности

- Скачивание книг в формате **PDF**
- Использование в брайзере Chrome
- Простой и интуитивный интерфейс
- Не требует установки дополнительного ПО

---

## 🧭 Как это работает

Плагин автоматически активируется, когда ты находишься на странице книги в **«Лань»** или **«Юрайт»**. Вот как всё происходит:

### 🔹 В ЭБС «Лань»

1. Перейди на страницу нужной книги (например, `https://reader.lanbook.com/book/*`).
2. Дождись полной загрузки страницы.
3. В правом верхнем углу страницы появится **кнопка** от плагина:
   **«Сохранить книгу»** 📥
4. Нажми её — и файл начнёт скачиваться автоматически.

### 🔹 В ЭБС «Юрайт»

1. Открой страницу книги (например, `https://urait.ru/course-viewer/*`).
2. Дождись загрузки контента.
3. В правом верхнем углу страницы появится **кнопка** от плагина:
   **«Сохранить книгу»** 📥
4. Кликни — и готово! Файл сохранится в твою папку «Загрузки».

### 🔹 В ЭБС «Айбукс»

1. Открой страницу книги (например, `https://ibooks.ru/bookshelf/*/reading`).
2. Дождись загрузки контента.
3. В правом верхнем углу страницы появится **кнопка** от плагина:
   **«Сохранить книгу»** 📥
4. Кликни — и готово! Файл сохранится в твою папку «Загрузки».

> 💡 Плагин работает **только на страницах отдельных книг**, а не на главной или в поиске. Убедись, что ты на странице чтения конкретной книги.

## 🛠 Установка в режиме разработчика (Chrome / Edge на Chromium)

> ⚠️ Эта инструкция подходит, если ты устанавливаешь расширение локально из исходников (например, для тестирования или личного использования).

1. **Скачай** или клонируй репозиторий на свой компьютер:

   ```bash
   git clone https://github.com/твой-ник/название-репозитория.git
   ```

2. Открой браузер **Google Chrome** (или **Edge**).
3. Перейди в меню расширений:
    → Введи в адресной строке: ```chrome://extensions```
    → Включи переключатель «**Режим разработчика**» в правом верхнем углу.

4. Нажми кнопку «**Загрузить распакованное расширение**».
5. Выбери папку с `build`.
6. Готово! 🎉 Расширение появится в списке и начнёт работать автоматически на сайтах «Лань», «Юрайт» и «Ibooks».

> 💡 Чтобы обновить расширение после изменений — просто нажми на иконку 🔄 «**Обновить**» рядом с ним в ```chrome://extensions```.
